NeuroQuest is an interactive, browser-based escape room game designed to challenge players with logic riddles, pattern recognition, and brain-teasing puzzles. Built using a modern web architecture, the application features an immersive and dynamic user interface created with React, HTML5, CSS3, and JavaScript on the frontend. On the backend, Java Servlets running on an Apache Tomcat server process core gameplay logic and handle user interactions, while a MySQL database securely stores player profiles, real-time game progress, puzzle states, and completion times for the global leaderboard. Players start by creating an account, entering the virtual room, and examining objects to solve sequential clues before time runs out to earn a spot at the top of the leaderboard.# NEUROQUEST

> **Abstract** : NeuroQuest is an interactive escape room game where players solve puzzles, find hidden clues, and explore different levels to escape. The game features Neuro, a virtual AI-inspired assistant that guides players and provides hints through predefined responses based on their progress. The project will be built using React for the frontend and Java for the backend, focusing on interactive gameplay, problem-solving, and an engaging user experience.
